## Open-source Work

I contribute across the [MTEB](https://github.com/embeddings-benchmark/mteb)
and [RTEB](https://github.com/embedding-benchmark/rteb) ecosystem, working on backend services, product analytics,
benchmark data flows, and leaderboard experiences.

### Analytics infrastructure

- Contribute to [`analytics-collector`](https://github.com/embedding-benchmark/analytics-collector), a FastAPI and
  MongoDB service that validates, enriches, rate-limits, and stores anonymous leaderboard events.
- Work includes privacy-conscious IP handling and aggregation pipelines for hourly, daily, funnel, and retention
  metrics.
- Contribute to the companion [
  `leaderboard-analytics-frontend`](https://github.com/embedding-benchmark/leaderboard-analytics-frontend), a SvelteKit
  dashboard for exploring those metrics.

### Leaderboard and benchmark contributions

- Added privacy-aware analytics instrumentation for search, filtering, sorting, comparison, downloads, sharing, and
  external navigation ([PR #29](https://github.com/embeddings-benchmark/leaderboard-frontend/pull/29)).
- Improved benchmark presentation and filtering across the MTEB/RTEB leaderboard, including event logging and UI
  behavior ([PR #3778](https://github.com/embeddings-benchmark/mteb/pull/3778)).
- Contributed RTEB result conversion for MTEB-compatible
  display ([PR #260](https://github.com/embeddings-benchmark/results/pull/260)).
- Fixed compare-page URL state handling for multi-value
  selections ([PR #25](https://github.com/embeddings-benchmark/leaderboard-frontend/pull/25)).
